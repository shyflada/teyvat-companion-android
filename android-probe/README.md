# Teyvat Companion для Android

## Збірка 0.1.0-android.8

Для першої перевірки почни в районі каньйону Світлої Корони з видимою
мінікартою. Відкрий Teyvat Companion, натисни **Start navigation**, вибери
Genshin у системному вікні й повернись до гри. Застосунок завантажить
публічні мітки та потрібні фрагменти карти HoYoLAB. Якщо позиція губиться,
ненадовго відкрий ігрову карту з міткою персонажа біля центру.

Перевір, чи видно відстань і чи стрілка реагує на поворот камери на місці.
Компас отримує свіжі кадри з інтервалом від 100 мс. Повне зіставлення
позиції оновлюється окремо, а стрілка використовує свіжу перевірену позицію.
Розпізнавання відкриття ввімкнено за замовчуванням. Коли програма бачить
анімацію біля актуальної цілі й підтверджує позицію, вона зберігає збір
і вибирає наступний сундук. **✓** поруч із компасом і **Confirm collected**
зберігають збір вручну, коли анімацію пропущено. **Next chest** пропускає ціль.
Обидві дії доступні також у сповіщенні під час навігації. **On map** відкриває
офіційну карту біля вибраного сундука. Через шестерню можна змінити мову,
вигляд компаса, поріг наближення й скасувати останню локальну зміну.

Після гри натисни **Sync with HoYoLAB** на головному екрані й увійди
у вікні офіційної карти. Застосунок за один сеанс автоматично надсилає зміни з черги,
поки карта відкрита. Сайт підтверджує кожну мітку після своєї відповіді.
Перед відкриттям HoYoLAB застосунок завершує
захоплення екрана й прибирає компас. Синхронізація працює, поки офіційна мапа
відкрита на передньому плані. Після повернення запусти навігацію знову.

Збірка працює з наземними цілями основної карти та горизонтальною відстанню.
Підтримка Android 10+ заявлена для ARM64. Синхронізацію в акаунті та
розпізнавання відкриттів у цій збірці потрібно підтвердити на телефоні.

Збірка на Windows використовує Android SDK 36, NDK r27c, Qt 6.11.3 для Android
ARM64 із WebP і SQLite, Qt 6.11.3 для Windows та OpenCV 4.12.0 для ARM64.
За наявності цих компонентів виконай `./scripts/build-android-navigation.ps1`.

## Проба захоплення

Перший APK перевіряє дві можливості на телефоні під час гри. Він підраховує
кадри з видимим вмістом і показує тестовий компас поверх Genshin. Лічильники
залишаються в пам’яті. Для встановлення заявлено Android 10 або новіший.

1. Запусти Genshin, потім відкрий Teyvat Companion Probe.
2. Дозволь показ поверх інших програм і почни захоплення. У системному вікні
   вибери Genshin, якщо доступний вибір застосунку. На старіших Android
   системний дозвіл охоплює весь екран.
3. Повернись у гру на 10 секунд. Перевір, чи видно компас і чи реагують
   ігрові кнопки. Зупини тест через сповіщення або в програмі й переглянь
   лічильник кадрів із видимим вмістом.

Для збірки на Windows потрібні JDK 17 або новіший, Android SDK Platform 36 та
Build Tools 36.0.0. Із кореня репозиторію виконай:

```powershell
./scripts/build-android-probe.ps1 -SdkRoot 'C:/Android/Sdk'
```

Скрипт створює `outputs/android-probe/Teyvat-Companion-Android-Probe.apk`
і перевіряє підпис локальним тестовим ключем.
