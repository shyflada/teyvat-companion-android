# Teyvat Companion для Android

1. Завантаж APK ARM64 зі сторінки [Releases](../../../releases). Для оновлення встанови APK поверх збірки з тим самим підписом, щоб зберегти локальний прогрес.
2. Дозволь оверлей компаса й натисни **Start navigation**. У системному вікні поширення екрана вибери Genshin Impact, якщо Android пропонує вибір застосунку.
3. Грай у горизонтальній орієнтації з видимою мінікартою. Якщо позиція загубилась, ненадовго відкрий внутрішню карту гри.
4. Відкрий сундук біля цілі. Коли програма розпізнає анімацію, вона збереже прогрес і вибере наступний сундук. **✓** біля компаса — резервне підтвердження.

Після гри натисни **Синхронізувати з HoYoLAB** і ввійди у вікні офіційної карти. Залиш карту відкритою, поки черга міток синхронізується. Для повернення до гри запусти навігацію знову.

У налаштуваннях можна змінити мову, регіон, вигляд компаса й режим розпізнавання. Збірка підтримує наземні цілі основної карти й показує приблизну горизонтальну відстань. [Збірка з коду](BUILD.md) · [Приватність](../PRIVACY.md)
