# Security

Report suspected vulnerabilities privately to the project maintainer. Include
the Android and app version, and steps to reproduce the problem using a fresh
test profile. Keep credentials, game IDs and private recordings out of reports.

HoYoLAB opens over HTTPS in a protected WebView after capture stops.
The app checks the official page and exact pin before using its marker control.
Updates stay queued until the site confirms them. See [privacy details](PRIVACY.md).
